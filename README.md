# Portfolio

Source for my GitHub Pages portfolio.

## Structure

- `index.html` — page markup and content
- `style.css` — styling
- `_config.yml` — GitHub Pages / Jekyll config

## Editing

- Swap the "About" paragraph in `index.html` for your own bio.
- Duplicate a `<li class="level">` block in the project list for each repo you want to feature, and drop in the real link.
- Push to the branch GitHub Pages is serving from — no build step needed.
